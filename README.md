# DBMS Lab Practicals

MySQL 8.0 scripts based on the attached Database Management System lab manual.

## Run order

Run `01_create_database_and_tables.sql` first. Then run Practicals 2-6 in order. Practical 7 and Practical 8 create their own databases. Practical 9 assumes the `CompanyDB` schema from Practical 2 is available.

Each script is self-contained where practical and includes comments explaining the expected operation.
